## 1. Базовая часть задания

### 1.1. Сравнительный анализ БЯЗ (ChatGPT-4o и GigaChat)
В рамках выполнения базовой части практики было проведено аналитическое сравнение коммерческих больших языковых моделей для автоматизации ответов вопросно-ответной системы:
* **ChatGPT-4o (OpenAI):** Демонстрирует глубокое понимание сложного технического контекста, высокую точность структурирования программного кода и вариативность ответов.
* **GigaChat (Сбер):** Показывает высокую скорость обработки русскоязычных запросов (минимальный пинг) и не требует использования прокси-серверов или VPN-сервисов для интеграции через API внутри инфраструктуры РФ.

### 1.2. Тестирование VK-бота проекта
Было выполнено ручной функциональное тестирование существующего VK-бота проекта методом "черного ящика". 
* **Позитивные сценарии:** Проверена отправка валидных текстовых запросов, бот корректно возвращает сгенерированный ИИ ответ.
* **Негативные сценарии:** При отправке пустых сообщений, стикеров или тяжелых медиафайлов зафиксированы случаи зависания обработчика. 
* **Результат:** Сформированы предложения по оптимизации кода (внедрение блоков `try-except` и валидация типов входящих сообщений) для предотвращения падения бота.
